# Alyan's Mini Store

## Store Description

Alyan's Mini Store is a simple online store webpage that displays different products, their prices, availability, and customer ratings.

It also provides product categories, a subscription form, and quick links for easy navigation.

## CSS Precedence

CSS precedence determines which styling rule is applied when multiple CSS rules target the same element and property.

The priority in this assignment is:

1. Inline CSS
2. Internal CSS
3. External CSS

The tagline appears green because inline CSS overrides the other paragraph color rules. Other paragraphs appear dark red because internal CSS overrides external CSS.
